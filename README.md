# 💰 Organizador Financeiro

Um aplicativo de linha de comando desenvolvido em **Python** para auxiliar na organização de receitas e gastos pessoais.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em programação, com foco na prática de conceitos fundamentais de Python e na construção de uma aplicação funcional.

## 🚀 Funcionalidades

* 👤 Identificação do usuário
* 💵 Registro do valor recebido no dia 15 ou 30
* 📋 Visualização dos gastos cadastrados
* ➕ Adição de novos gastos
* 🗑️ Remoção de gastos
* 🧮 Cálculo do total de despesas
* 💰 Cálculo do saldo restante
* 📊 Consulta das informações do pagamento
* 🔄 Menu interativo para gerenciamento das opções

## ▶️ Como executar

### Pré-requisitos

É necessário ter o **Python 3** instalado no computador.

### Executando o projeto

Clone este repositório:

```bash
git clone https://github.com/victortech-dados/Organizador-Financeiro.git
```

Entre na pasta do projeto:

```bash
cd Organizador-Financeiro
```

Execute o programa:

```bash
python organizador_financeiro.py
```

## 💡 Como funciona

Ao iniciar o programa, o usuário informa seu nome e escolhe qual pagamento deseja organizar:

* Dia 15
* Dia 30

Depois disso, é apresentado um menu que permite visualizar, adicionar e remover gastos, além de calcular automaticamente o saldo restante.
